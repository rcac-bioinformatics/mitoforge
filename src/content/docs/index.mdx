Assemble, circularise and annotate animal mitochondrial genomes from PacBio HiFi or
Illumina paired-end reads, for many samples at once.

You write one samplesheet. You get one finished mitogenome per sample, annotated,
circularised and rotated to start at tRNA-Phe, plus a table telling you how each sample
went.

## What it does

<MetroMap alt="mitoforge pipeline overview. PacBio HiFi reads go through MitoHiFi in reads mode; Illumina paired-end reads go through fastp and GetOrganelle. A reference mitogenome, either supplied in the samplesheet or fetched by findMitoReference, seeds both routes. Both routes converge on MitoHiFi in contigs mode, which produces the finished mitogenome, the summary table and the MultiQC report." />

Whichever route a sample took, it goes through the same finishing step, so every sample
ends up with the same files in the same places.

Hollow stations are steps that only run when they are needed: `findMitoReference` when
the samplesheet gives a species name rather than a reference, `samtools fastq` when the
HiFi reads arrive as BAM, and `fastp` unless you pass `--skip_trimming`.

### What goes in

You hand the pipeline one file, `--input samplesheet.csv`. Everything else on the map is
a path named in one of its columns, so the three file icons on the left are three groups
of columns in that one sheet rather than three things you supply separately.

| Icon on the map        | Samplesheet columns     | Which rows                      |
| ---------------------- | ----------------------- | ------------------------------- |
| `FASTA/GBK`, section 1 | `ref_fa` and `ref_gb`   | rows that name a reference file |
| `FASTQ/BAM`, section 2 | `fastq_1` **or** `bam`  | rows with `platform: hifi`      |
| `FASTQ`, section 3     | `fastq_1` and `fastq_2` | rows with `platform: illumina`  |

One row is one sample, and the `platform` column is what decides whether that row takes
the orange line or the blue one. Every row needs reads and a reference mitogenome.

Reads come in exactly one of two ways: `fastq_1` (plus `fastq_2` for Illumina), or `bam`
for an unaligned PacBio BAM. Filling in both is an error, and `bam` is HiFi only. That is
why `samtools fastq` is hollow, it only runs for the rows that arrived as BAM.

The reference has three routes, and the map draws only the first two:

- `ref_fa` and `ref_gb`, the files you supply, which is the `FASTA/GBK` icon
- `species`, a scientific name that `findMitoReference` looks up at NCBI, which is why
  that station is hollow
- `ref_fa: hifi:<sample>`, reusing the finished mitogenome of another row in the same
  sheet, for Illumina rows only. The map leaves this one out because the edge runs
  backwards out of the finishing step and a metro map has to stay acyclic. It is worked
  through in [Short reads using HiFi mitogenomes](/mitoforge/cases/short-reads-from-hifi/).

[Samplesheet](/mitoforge/samplesheet/) documents every column.

## What it is built on

mitoforge does not assemble anything itself. It wraps
[MitoHiFi](https://github.com/marcelauliano/MitoHiFi) and
[GetOrganelle](https://github.com/Kinggerm/GetOrganelle), and everything those two call
in turn, in a Nextflow pipeline built on the [nf-core](https://nf-co.re) template. All
of it runs in pinned containers, so a run on your laptop and a run on the cluster use
exactly the same software.

## Where it runs

| Where                  | Profile           | Container engine |
| ---------------------- | ----------------- | ---------------- |
| Gautschi (Purdue RCAC) | `purdue_gautschi` | Apptainer        |
| Your laptop            | `docker`          | Docker           |

The Gautschi profile comes from
[nf-core/configs](https://github.com/nf-core/configs/blob/master/conf/purdue_gautschi.config),
so it is maintained by the people who run the cluster rather than duplicated here. It
picks the partition from each task's memory request; all you supply is
`--cluster_account`.

:::caution[The cluster profile is untested with this pipeline]
The profile itself is used by other nf-core pipelines on Gautschi, but mitoforge has
not yet completed a run there. Please
[open an issue](https://github.com/rcac-bioinformatics/mitoforge/issues) with anything
that does not work.
:::
